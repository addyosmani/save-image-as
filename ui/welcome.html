SaveImage is installed

Pick the format you actually need, without a round trip through a website.

How it works

Right-click any image On any page, in any frame.
Pick “Save Image As...” → JPEG, PNG or WebP Or “Original file” to download exactly the bytes the server sent, untouched.
It lands in your Downloads folder Converted on your machine, at the quality you chose.

Worth knowing

Your images never leave this machine Pixels are decoded and re-encoded by code running on your computer. The only request made is the one that retrieves the image you clicked.
It fetches the best source it can find Follows srcset to the largest version, and asks Cloudinary for the untransformed original instead of the resized copy on the page.
No silent format lies Every encode is verified against its real MIME type before saving, so a .webp file is always genuinely WebP.
No re-encoding when it would only hurt Saving a PNG as PNG copies the original bytes rather than putting them through a lossy round trip.
