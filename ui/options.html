SaveImage

Every setting below affects work done locally, by your own copy of Chrome. The extension talks to exactly one thing: the server hosting the image you clicked.

Where files go

Chrome extensions can only write inside your Downloads folder — a subfolder is created there. Existing files are never overwritten; a number is appended instead.

Notifications

Encoder support

Probed directly from your browser at install time. A format only appears in the right-click menu once its encoder has been proven to work, so SaveImage can never write a file whose contents disagree with its extension.
